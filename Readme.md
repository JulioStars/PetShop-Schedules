# Mundo Pet - Aplicação de Agendamento para Pet Shop

[![Status do Projeto](https://img.shields.io/badge/Status-Concluído-brightgreen)](https://github.com/JulioStars/PetShop-Schedules)

Esta é uma aplicação web responsiva de agendamento para um Pet Shop. O objetivo principal é permitir que usuários adicionem novos agendamentos, visualizem os agendamentos organizados por período (manhã, tarde e noite) e excluam agendamentos existentes. Este projeto foi desenvolvido inteiramente do zero, abrangendo a estrutura HTML, a estilização CSS e toda a lógica com JavaScript.

## Visão Geral Rápida

* **Propósito:** Desenvolver uma aplicação completa de agendamento para um Pet Shop, oferecendo funcionalidades de criação, visualização e exclusão de agendamentos.
* **Complexidade:** Envolve a aplicação de conceitos mais avançados de JavaScript, incluindo funções assíncronas, JavaScript Modules e potencialmente um processo de compilação.
* **Responsividade:** A aplicação é totalmente responsiva, proporcionando uma boa experiência em diversos dispositivos.

## Funcionalidades Chave

* **Adicionar Agendamento:** Formulário para que o usuário possa inserir os detalhes de um novo agendamento (data, horário, serviço, nome do pet, etc.).
* **Visualização por Período:** Organização e exibição dos agendamentos separados por turnos (manhã, tarde e noite), facilitando a visualização da agenda.
* **Excluir Agendamento:** Funcionalidade para remover agendamentos existentes.
* **Funções Assíncronas:** Utilização de `async/await` para lidar com operações assíncronas (como interações com um possível backend futuro ou simulação de carregamento de dados).
* **JavaScript Modules:** Organização do código JavaScript em módulos para melhor estruturação e manutenção.
* **Processo de Compilação (Potencial):** Utilização de ferramentas como Webpack para otimizar e agrupar os arquivos JavaScript e outros assets. Utilização do Dayjs para facilitar a manipulação de datas e horários.
* **Responsividade:** Layout fluido e adaptável a diferentes tamanhos de tela.

## Tecnologias Utilizadas

* **HTML:** Estrutura da página web e dos elementos da aplicação (formulários, listas, botões).
* **CSS:** Estilização visual da aplicação e implementação do layout responsivo.
* **JavaScript:** Lógica completa da aplicação, incluindo:
    * Manipulação do DOM para interatividade.
    * Funções para adicionar, visualizar e excluir agendamentos.
    * Funções assíncronas para operações que podem levar tempo.
    * Utilização de JavaScript Modules (`import/export`) para organização do código.
    * Configuração e uso de um compilador (Webpack).
